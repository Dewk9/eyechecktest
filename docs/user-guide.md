# คู่มือการใช้งาน (ฉบับย่อ)

คู่มือฉบับเต็มพร้อมภาพประกอบและ FAQ อยู่ในเว็บไซต์ที่ `/pages/guide.html`

1. **สมัครสมาชิก** — เลือกบัญชีส่วนบุคคล หรือบัญชี อสม./เจ้าหน้าที่ (ต้องมีโค้ดจากหน่วยงาน)
2. **เข้าสู่ระบบ** — เลือก "จดจำฉันในอุปกรณ์นี้" เฉพาะเครื่องส่วนตัว
3. **บัญชีส่วนบุคคล** — ซักประวัติครั้งเดียว แก้ไขได้ ดูประวัติ/แนวโน้มของตนเอง
4. **บัญชีเจ้าหน้าที่** — จัดการรายชื่อผู้เข้ารับการตรวจ ซักประวัติใหม่ทุกครั้ง ดูประวัติรายบุคคล เปรียบเทียบผล
5. **ซักประวัติ** — 3 ส่วน; อาการฉุกเฉินจะแจ้งให้พบแพทย์ทันที
6. **ทดสอบการมองเห็น** — ปรับเทียบหน้าจอก่อน ทดสอบตาขวาแล้วตาซ้าย
7. **ถ่ายภาพ** — เลือกตา เปิดกล้อง เริ่มสแกนแบบ Real-time ถ่ายเมื่อกรอบเป็นสีเขียว
8. **อัปโหลดภาพ** — JPG/PNG/WEBP ≤ 8 MB
9. **วิเคราะห์ด้วย AI** — ดูสถานะแต่ละขั้น; หาก AI ไม่ได้เชื่อมต่อ ระบบจะแจ้งชัดเจน
10. **ดูผล** — ผล AI / ผลซักประวัติ / ผลทดสอบสายตา / สรุปความเสี่ยง แยกกัน
11. **บันทึกผล** — กด "บันทึกผลการตรวจ" (ผลที่บันทึกแล้วจะนับในแดชบอร์ด)
12. **ประวัติย้อนหลัง** — ค้นหา กรอง เรียงลำดับ ลบ (ยืนยันก่อน)
13. **Dashboard** — จำนวนการตรวจ ผลที่ต้องส่งต่อ กราฟวงกลมและแนวโน้ม
14. **พิมพ์รายงาน** — ปุ่ม "พิมพ์รายงาน" หรือบันทึกเป็น PDF
15. **ข้อควรระวัง** — ผลเป็นการคัดกรองเบื้องต้นเท่านั้น ไม่ใช่การวินิจฉัย
